
# NYSC Knowledge Quiz

A responsive quiz application that tests users' knowledge of the National Youth Service Corps (NYSC). Users can enter their names, answer timed questions, view their scores, and save quiz results to a Supabase database.

## Features
- User name registration
- Randomised quiz questions
- Countdown timer
- Instant answer feedback
- Score review and result storage

## Tech Stack
React, Tailwind CSS, Node.js, Express.js, PostgreSQL (Supabase).

## Run Locally
1. Clone the repository.
2. Install dependencies using `npm install` in the frontend and `backend` directories.
3. Configure the required environment variables.
4. Start the backend and frontend servers.
